Architecture Overview

SPA Structure

Single Page Application with client-side routing via goTo(screenId) function. No page reloads — UI updates dynamically based on state.screen.

Screen Phases

Phase 1: Onboarding (19 screens) Phase 2: Dashboard (7 screens)

State Management

Single state object (~33 properties) initialized from localStorage labhya_store_v1. All UI rendered via render() function.

Navigation Flow

App starts → loadSavedStore() → check loggedInMobile → dashboard if logged in, else onboarding

  1. welcome → language → mobile → OTP → profile → dashboard
  2. Returning users skip straight to dashboard

Key Functions

  • loadSavedStore() — Restores state from localStorage
  • persistStore() — Saves state to localStorage
  • handleGetStarted() — Entry point, checks auth state
  • verifyOtp() — Validates OTP, routes to dashboard or profile
  • saveCurrentProfileToStore() — Persists profile after onboarding

Onboarding Workflow

  1. Language selection → store langCode
  2. Mobile number input → validate 10 digits
  3. Submit → generate mock OTP, navigate to OTP screen
  4. OTP verification → validate 6 digits
  5. If savedProfiles[mobile] exists → restore profile → dashboard
  6. If new user → full profile collection (name, DOB, gender, PIN, occupation, etc.)
  7. confirmProfileAndEnter() → saveCurrentProfileToStore() → dashboard

Authentication & Authorization State

Authentication State

The application uses localStorage-based authentication with no external auth provider.

Key State Properties

  • loggedInMobile (string) — Mobile number of currently logged-in user, or empty string
  • savedProfiles (object) — {mobile: {profile data}} map of all registered users
  • langCode (string) — Selected language code: 'en', 'hi', 'kn', 'ta', 'te'
  • digiLockerConnected (boolean) — Whether DigiLocker permissions have been granted

Authentication Flow

New User

  1. App start → handleGetStarted() → no loggedInMobile → language screen
  2. Select language → persistStore()
  3. Enter mobile → submitMobile() → generate mock OTP → OTP screen
  4. Verify OTP → verifyOtp() → no saved profile → full onboarding
  5. Complete profile → saveCurrentProfileToStore() → dashboard

Returning User

  1. App start → loadSavedStore() → restore state from localStorage
  2. handleGetStarted() → loggedInMobile exists → Object.assign() profile
  3. Navigate directly to dashboard — profile creation skipped
  4. All profile data already available from previous session

Authorization Levels

  • Guest: Can view welcome, language selection
  • Registered User: Full access after mobile verification + profile completion
  • DigiLocker Connected: Access to document verification features
  • Logged Out: Session cleared, returns to welcome screen

Session Persistence

All state persists in localStorage under key labhya_store_v1.
